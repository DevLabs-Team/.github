## Quienes somos

Somos una organizacion de desarrollo formada por estudiantes y desarrolladores apasionados por la tecnologia. Construimos soluciones innovadoras, contribuimos al open source y compartimos conocimiento.

## Nuestros valores

| | |
|---|---|
| **Innovacion** | Exploramos nuevas tecnologias para crear soluciones que marcan la diferencia |
| **Comunidad** | Compartimos conocimiento, crecemos juntos y construimos en abierto |
| **Excelencia** | Codigo limpio, buenas practicas y estandares altos en todo lo que hacemos |
| **Velocidad** | Desarrollo agil y eficiente, sin sacrificar la calidad |
