## English

### Getting Help

If you have a question or need help, here's how to reach us:

1. **GitHub Issues** — Open an issue in the relevant repository
2. **Email** — Contact us at devlabs@elmarcels.xyz
3. **Discord** — Coming soon

### Reporting Bugs

When reporting a bug, please include:

- **Description** — What happened?
- **Steps to reproduce** — How can we replicate the issue?
- **Expected behavior** — What should have happened?
- **Screenshots** — If applicable
- **Environment** — OS, browser, device

### Feature Requests

We love ideas! When suggesting a feature:

- Describe the problem it solves
- Explain how it would work
- Give examples of use cases

### Response Times

| Type | Estimated Time |
|------|---------------|
| Critical bugs | 24-48 hours |
| General issues | 3-5 days |
| Feature requests | Reviewed weekly |
